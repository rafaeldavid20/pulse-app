Run `npx vite tests/manual/offline-cache --host 127.0.0.1 --port 4178` and open the local URL in a browser. The harness deliberately makes IndexedDB.open fail, initializes the Firebase SDK with the same persistent multi-tab cache as the application, disables network and checks that a local write appears in an onSnapshot listener. It uses a demo-only project identity and does not connect to production. A PASS demonstrates fallback to memory in that browser; it does not test synchronization after reconnect or cross-tab persistence.
